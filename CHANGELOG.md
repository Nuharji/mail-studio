# Changelog

## 0.1.0 — 2026-11-16
**First version** — Mail Studio, the e-mail program of the Studio family (Pre-Alpha).
- IMAP / SMTP accounts with presets for iCloud, Gmail, Outlook, Yahoo, GMX, WEB.DE, Telekom, Posteo, mailbox.org, AOL,
  freenet and Proton Mail (Bridge); passwords in the system keychain.
- Folders, message list, search, flags, archive / junk / delete / move; HTML mail without scripts, remote images on request.
- Write, reply, forward, attachments (also drag & drop), drafts on the server; offline cache for reading.
- `mailto:` links; MCP server (`--mcp`): mail_accounts, mail_folders, mail_list, mail_read, mail_search, mail_draft.
- All Studio themes and layouts, logo follows the theme, German / English, customizable shortcuts.
